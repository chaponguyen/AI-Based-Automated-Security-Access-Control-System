Dán nguyên khối dưới đây vào công cụ (mở công cụ ở thư mục gốc project):

```
Đọc AGENTS.md rồi docs/context/ (PROJECT_BRIEF, DB_SCHEMA, API_CONTRACT, DECISIONS_LOG, PROGRESS_LOG) trước khi viết code. Mở docs/reports/B3.md để xem checklist.

Bạn là A1 (AI Engine). Việc: B3 — Embedding và so khớp.
Mục tiêu: Tạo embedding 512 chiều chuẩn hóa L2 và so khớp với kho theo người.
Chỉ được sửa: backend/ai/embedder.py, matcher.py. Không được sửa: backend/api/, backend/database/, frontend/, embedded/.

Các checkpoint, làm lần lượt, mỗi lần đúng một checkpoint:
CP-01 get_embedding: chạy model nhận diện, chuẩn hóa L2  [kiểm tra: độ dài vector bằng 1]
CP-02 Hàm cosine similarity  [kiểm tra: so 2 vector giống nhau bằng 1]
CP-03 best_match: mỗi người lấy trung bình top-3 độ giống, trả (user_id|None, similarity)  [kiểm tra: test kho giả]
CP-04 Script đo cặp cùng người và khác người trên test_data/  [kiểm tra: xuất bảng similarity ra docs/reports/B3.md]

QUY TẮC BÁO CÁO THEO CHECKPOINT (bắt buộc, quan trọng hơn tốc độ):
1. Làm đúng MỘT checkpoint rồi dừng lại (một bảng, một nhóm cột, một hàm, một route hoặc một component).
2. Tự kiểm tra tối thiểu (py_compile, import, chạy thử nhỏ).
3. NGAY LẬP TỨC ghi nhật ký, trước khi git commit và trước khi sang checkpoint kế:
   python scripts/log_checkpoint.py B3 CP-xx --file <file vừa sửa> --auto --did "<đã làm gì, nêu tên bảng, cột, hàm cụ thể>" --why "<vì sao làm vậy>" --check "<đã kiểm tra thế nào>" --todo "<bước kế tiếp>"
   (--auto tự tìm số dòng đã viết. Có thể lặp --file nếu sửa nhiều file.)
4. Rồi mới: python scripts/agent_commit.py A1 "[B3] CP-xx <mô tả> - A1"
5. Cấm gộp nhiều checkpoint rồi viết báo cáo sau, cấm để báo cáo đến cuối việc.
6. Thấy sắp hết token hoặc quota: dừng việc mới và chạy
   python scripts/log_checkpoint.py B3 --handoff --note "<đang dở gì, file và dòng nào, bước kế tiếp>"
```
